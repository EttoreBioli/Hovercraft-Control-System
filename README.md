# Hovercraft-Control-System

This repository contains the MATLAB and Simulink implementation of a cascade control architecture for a nonlinear, underactuated hovercraft.

The project was developed as part of the Technological Processes Control course (Master's Degree in Robotics and Automation Engineering, University of Pisa).

## Project Overview

The objective of this project is to stabilize and control a 3-DOF hovercraft equipped with only two longitudinal thrusters (an underactuated system). The control strategy relies on a hierarchical cascade architecture:

Kinematic Level (Outer Loop): Computes the desired linear and angular velocities required to reach a target position and orientation, or to follow a predefined path (e.g., a circular trajectory).

Dynamic Level (Inner Loop): Drives the thrusters to track the reference velocities generated by the kinematic controller while strictly respecting the physical limits of the actuators.

## Key Features & Methodologies

System Linearization & Analysis: Mathematical linearization of the nonlinear state equations, stability analysis, and verification of reachability and observability.

Constrained Optimal Control: Implementation of a discrete-time optimal control strategy using constrained least squares to respect thruster saturation limits.

Model Predictive Control (MPC): Advanced real-time optimization to handle dynamic velocity tracking in the inner loop.

Cascade Integration: Complete Simulink testing environment bridging the kinematic and dynamic levels for point stabilization and path following maneuvers.
